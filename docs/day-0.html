🎒 दिवस 0 — एकदाच तयारी, धडा 01 आधी

तीस मिनिटे, एकदाच, आणि या कोर्समधला प्रत्येक प्रयोग सुरक्षित आणि स्वस्त होतो. इथली प्रत्येक पायरी कोर्स नंतर समजावणार आहे — आज फक्त करा. पुढे जाण्याआधी ✅ ओळीवर खूण करा.

1AWS खाते तयार करा — आणि मास्टर किल्ली कुलूपबंद करा

तुमच्या ताब्यातल्या ईमेलने aws.amazon.com वर नोंदणी करा. हे login म्हणजे root खाते (धडा 01 ची मास्टर किल्ली). तीन गोष्टी करा आणि मग रोजच्या कामासाठी ते पुन्हा कधीच वापरू नका:

  • root वर MFA चालू करा (Security credentials → MFA)
  • root साठी access keys बनवू नका
  • 12-अंकी account ID लिहून ठेवा — ARN साठी लागेल

✅ root ला MFA आहे, आणि तुम्ही त्यातून logout करणार आहात.

2स्वतःसाठी IAM user बनवा (root नव्हे) — किंवा अजून चांगले, Identity Center user

IAM → Users → console प्रवेश आणि MFA सह you बनवा. फक्त कोर्ससाठी AdministratorAccess जोडा (धडा 06 तुम्हाला याबद्दल वाईट वाटायला लावेल, हाच मुद्दा). तुमच्या खात्यात IAM Identity Center (SSO) असेल तर त्याऐवजी ते वापरा — ते तात्पुरती credentials देते, नेमके जे धडा 04 शिकवतो.

✅ तुम्ही MFA सह IAM user म्हणून login करू शकता; root logout झाले आहे.

3AWS CLI install आणि configure करा

# macOS: brew install awscli      · Windows: winget install Amazon.AWSCLI      · Linux: see docs.aws.amazon.com/cli
aws configure sso        # Identity Center users — preferred (temporary credentials)
aws configure            # IAM user — creates an access key for YOUR laptop only; rotate it after the course
aws sts get-caller-identity   # must show your IAM user or SSO role, never "root"

संपूर्ण कोर्ससाठी एक region निवडा (प्रयोग मुळात us-east-1 वापरतात; ap-south-1 मुंबईही चालते — सगळीकडे तेच ठेवा).

✅ get-caller-identity user/ किंवा assumed-role/ असलेला ARN छापते.

4Terraform install करा

# macOS: brew install terraform      · Windows: winget install Hashicorp.Terraform      · Linux: see developer.hashicorp.com/terraform/install
terraform version

या कोर्समधला प्रत्येक पैसे लागणारा प्रयोग म्हणजे एक .tf फाइल असलेला फोल्डर आणि दोन commands: terraform apply आणि, नेहमी, terraform destroy.

✅ terraform version 1.x छापते.

5$5 चा budget अलार्म लावा — तारेचा सापळा

Billing → Budgets → $5/महिना चे cost budget बनवा, 80% आणि 100% वर ईमेल सूचनेसह. AWS वरची ही सर्वात मौल्यवान सुविधा का हे धडा 20 समजावतो; आज फक्त चालू करा. Cost Explorer ही आत्ताच चालू करा — ते फक्त पुढच्या नोंदी ठेवते.

✅ budget अस्तित्वात आहे आणि तुम्हाला पुष्टीचा ईमेल आला.
